# ვორკშოპი 1: AI-ს ამბავი

დამოუკიდებელი, 24-სლაიდიანი HTML პრეზენტაცია ქართულ ენაზე. პაკეტის ინსტალაცია და ქსელი არ სჭირდება. 10-წუთიანი შესვენება არის ზუსტად შუაში, სლაიდ 13-ზე.

## გაშვება

გახსენით `index.html` თანამედროვე ბრაუზერში, ან ამ საქაღალდეში გაუშვით `python3 -m http.server 8000` და გახსენით `http://localhost:8000`.

## მართვა

- მარცხენა/მარჯვენა ისრები ან Space: ნავიგაცია
- Home / End: პირველი / ბოლო სლაიდი
- F: სრული ეკრანი
- N: სპიკერის ჩანაწერები
- Escape: სრული ეკრანიდან გამოსვლა
- „სლაიდები“: მიმოხილვის ბადე

## რედაქტირება

სლაიდები 1–7 პირდაპირ აჩვენებს `images/slide1.png`-დან `images/slide7.png`-მდე ფაილებს. ისინი არ იჭრება, არ იცვლება და არ ანიმირდება.

ყველა დანარჩენი სლაიდის ტექსტი, ჩანაწერი და ქრონომეტრაჟი `app.js` ფაილის `S` მასივშია. Tokenizer, შემდეგი ნაწილის პროგნოზი, ნეირონული ქსელი, pre-training, post-training და prompt-ის მაგალითები სლაიდებზე 11–19 მდებარეობს.

ვიზუალურ ანიმაციებს აქვს `prefers-reduced-motion` მხარდაჭერა: მომხმარებლის მოძრაობის შემცირების პარამეტრისას ისინი პრაქტიკულად ითიშება.
